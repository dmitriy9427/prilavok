# Разбор кода: файл за файлом

Главы учебника объясняют **идеи**: протокол, переподключение, докачку, кэш. Здесь —
**конкретный код**: ключевые файлы «Прилавка» разобраны порциями, после каждой — что она делает и
зачем.

## Как устроена каждая страница

1. **Где это** — что видит человек на экране (или чего не видит, если это «под капотом»).
2. **Что делает** — по пунктам, человеческим языком.
3. **Как пользоваться** — пример вызова.
4. **Код по частям** — настоящий код с объяснением.
5. **Что будет, если…** — уберите строку и посмотрите, что сломается.
6. **Проверьте себя** — вопросы с ответами.
